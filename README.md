# ربات چندکاره تلگرام

ربات تلگرامی با ابزارهای تصویر، فایل، متن، یادآوری و آب‌وهوا — همه با کتابخونه‌ها و API‌های رایگان.

## قابلیت‌ها

| دسته | دستور |
|---|---|
| QR Code | `/qr <متن یا لینک>` |
| تبدیل/تغییر عکس | فقط عکس بفرست، دکمه‌ها میان |
| حذف پس‌زمینه | همون‌جا از دکمه‌ها |
| عکس به PDF | `/img2pdf` سپس عکس‌ها، بعد `/done` |
| PDF به عکس | فایل PDF رو بفرست |
| فشرده‌سازی (ZIP) | `/zip` سپس فایل‌ها، بعد `/donezip` |
| کوتاه‌کننده لینک | `/shorten <لینک>` |
| رمز عبور تصادفی | `/password [طول]` |
| یادآوری | `/remind 2h \| متن` یا `/remind 2026-07-25 09:00 \| متن` |
| لیست یادآوری‌ها | `/reminders` |
| حذف یادآوری | `/delremind <شماره>` |
| آب‌وهوا | `/weather <شهر>` |

## API‌های استفاده‌شده (همه رایگان و بدون انقضا)

- **Open-Meteo** (آب‌وهوا و geocoding) — بدون نیاز به API key
- **is.gd** (کوتاه‌کننده لینک) — بدون نیاز به API key
- کتابخونه‌های محلی: `qrcode`, `Pillow`, `PyMuPDF`, `rembg` (اختیاری)

هیچ‌کدوم از این‌ها محدودیت زمانی (trial) ندارن، پس نگران "چند روزه شدن" نباش.

## راه‌اندازی محلی (برای تست قبل از هاست)

```bash
git clone <آدرس ریپوی خودت>
cd telegram_bot
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt

# اختیاری: برای فعال‌کردن حذف پس‌زمینه (نیاز به RAM بیشتر)
pip install -r requirements-removebg.txt

cp .env.example .env
# BOT_TOKEN رو داخل .env بذار (از @BotFather بگیر)

export $(cat .env | xargs)   # یا متغیرها رو دستی ست کن
python main.py
```

## دیپلوی روی Render (رایگان) — قدم‌به‌قدم

1. کد رو توی یه ریپوی گیت‌هاب (GitHub) پابلیک یا خصوصی بذار.
2. برو به [render.com](https://render.com) و با گیت‌هاب لاگین کن.
3. **New +** → **Background Worker** رو انتخاب کن (نه Web Service، چون این ربات وب‌سرور نداره و فقط polling می‌کنه).
4. ریپوی خودت رو وصل کن.
5. تنظیمات build:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
6. تو بخش **Environment**، متغیر `BOT_TOKEN` رو با توکن واقعی ربات اضافه کن.
7. **Deploy** بزن.

> ⚠️ نکته مهم: پلن رایگان Render برای **Background Worker** برخلاف Web Service، به خواب نمی‌ره (چون اصلاً درخواست HTTP دریافت نمی‌کنه) — ولی محدودیت ساعت رایگان ماهانه داره؛ توی داشبورد Render مقدار دقیقش رو چک کن چون گاهی تغییر می‌کنه.

### اگه SQLite بعد از ری‌استارت پاک شد چیکار کنم؟

روی پلن رایگان Render، دیسک **پایدار (persistent) نیست** — یعنی بعد از هر دیپلوی یا ری‌استارت، فایل `bot_data.db` (و یادآوری‌های ذخیره‌شده) از بین می‌ره. برای رفع این مشکل دو راه داری:

1. از **Render Disk** (اگه پلن پولی داری) استفاده کنی.
2. یا یادآوری‌ها رو توی یه دیتابیس رایگان بیرونی مثل [Supabase](https://supabase.com) (پلن رایگان PostgreSQL) نگه داری. اگه خواستی این بخش رو با هم پیاده کنیم، بگو تا کدش رو عوض کنم.

فعلاً برای شروع و تست، همون SQLite محلی کافیه.

## دیپلوی روی Railway (جایگزین)

مشابه Render:
1. ریپو رو به [railway.app](https://railway.app) وصل کن.
2. متغیر `BOT_TOKEN` رو ست کن.
3. Start Command: `python main.py`

Railway پلن رایگانش بر پایه‌ی اعتبار ماهانه‌ست (نه زمان)، پس بسته به مصرف ربات ممکنه زودتر یا دیرتر تموم بشه.

---

## نکات مهم درباره‌ی محدودیت‌های هاست رایگان

- **`ENABLE_REMOVE_BG`**: اگه سرورت کمتر از ۱ گیگ RAM داره، این متغیر رو `false` بذار تا قابلیت حذف پس‌زمینه غیرفعال بشه (چون `rembg` حافظه‌ی زیادی مصرف می‌کنه و ممکنه ربات کرش کنه).
- **`MAX_FILE_SIZE_MB`** (در `config.py`): برای جلوگیری از پر شدن حافظه، حجم فایل‌های ورودی محدود شده (پیش‌فرض ۱۵ مگابایت).
- **`MAX_PDF_PAGES`** و **`MAX_FILES`**: برای جلوگیری از پردازش سنگین، تعداد صفحات PDF و تعداد فایل‌های zip محدود شدن.
- ربات با **polling** کار می‌کنه (نه webhook)، پس نیازی به دامنه یا SSL نداری — فقط باید سرویس همیشه در حال اجرا باشه (به همین خاطر Background Worker نه Web Service).

## ساختار پروژه

```
telegram_bot/
├── main.py                  # نقطه‌ی شروع، ثبت هندلرها
├── config.py                 # تنظیمات و متغیرهای محیطی
├── database.py                # مدیریت SQLite برای یادآوری‌ها
├── requirements.txt           # وابستگی‌های اصلی
├── requirements-removebg.txt  # وابستگی اختیاری برای حذف پس‌زمینه
├── Procfile                   # دستور اجرا برای Render/Railway
└── handlers/
    ├── start.py                # /start و /help
    ├── qr_tool.py               # /qr
    ├── image_tools.py            # پردازش عکس (تبدیل، ریسایز، فیلتر، حذف پس‌زمینه)
    ├── pdf_tools.py               # عکس‌به‌PDF و PDF‌به‌عکس
    ├── zip_tools.py                # ساخت فایل zip
    ├── text_tools.py                # کوتاه‌کننده لینک، رمز عبور
    ├── weather.py                    # آب‌وهوا
    └── reminders.py                   # یادآوری‌ها
```
